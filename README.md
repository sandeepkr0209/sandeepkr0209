## 🛡️ CodeShieldAI

**AI-Assisted Web Application Security Analysis Platform**

CodeShieldAI is an AI-assisted security analysis platform designed to analyze authorized web applications and source code using a combination of traditional security tooling and AI-powered reasoning.

### ✨ Highlights

- 🔍 Performs **web application reconnaissance and attack-surface analysis**
- 🌐 Discovers pages, routes, forms, endpoints, parameters, and application structure
- 🧩 Supports **source-code security analysis**
- 🔎 Integrates **Semgrep, Bandit, and Tree-sitter**
- 🤖 Uses LLM-powered security reasoning to analyze security observations
- 📚 Designed with a security knowledge base using **OWASP, CWE, CAPEC, and secure coding references**
- 🧠 Follows an **Observation → Hypothesis → Controlled Test → Evidence → Verification** workflow
- 📊 Generates structured security findings and reports
- 🗃️ Uses PostgreSQL with SQLAlchemy for persistent project and scan data
- ⚡ Built with FastAPI backend and React frontend

### Tech Stack

`Python` `FastAPI` `React` `TypeScript`  
`PostgreSQL` `SQLAlchemy` `Groq` `Playwright`  
`Semgrep` `Bandit` `Tree-sitter` `ChromaDB`

🔗 **Repository:**
